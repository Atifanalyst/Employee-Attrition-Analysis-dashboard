# Employee-Attrition-Analysis-dashboard

1. Project Title / Headline

Employee Attrition Analysis | Power BI HR Analytics Dashboard

3. Short Description / Purpose

An interactive HR analytics dashboard built to understand employee attrition, identify key reasons behind employee exits, and uncover workforce patterns. The project helps HR and management move beyond basic attrition numbers and make more informed, data-driven retention decisions.

3. Tech Stack

Power BI
Power Query
DAX
Microsoft Excel
Data Visualization

5. Features & Highlights

KPI Dashboard – Tracks key workforce and attrition metrics at a glance.
Attrition Analysis – Analyzes overall employee attrition and exit patterns.
Department Analysis – Identifies departments with higher attrition levels.
Exit Reason Analysis – Highlights the major reasons employees leave.
Employee Insights – Analyzes factors such as job satisfaction, tenure, salary, performance, overtime, and work-life balance.
Interactive Visualizations – Uses charts, cards, slicers, and filters for easy exploration.
Data Transformation – Cleaned and prepared HR data using Power Query.
DAX Measures – Created calculated metrics to support meaningful HR analysis.
Management Insights – Converts workforce data into actionable insights that can support employee retention strategies.

Project Goal:

To turn raw employee data into a clear, interactive dashboard that helps HR teams dentify attrition hotspots, understand why employees leave, and make better workforce decisions.
